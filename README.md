# Blinkit Sales Dashboard — Excel

## Overview
An interactive sales performance dashboard for Blinkit 
(quick commerce) data built using Microsoft Excel.

## Key Metrics Tracked
- Revenue by category
- Order volume trends
- City-wise breakdown
- Delivery performance

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Conditional Formatting
